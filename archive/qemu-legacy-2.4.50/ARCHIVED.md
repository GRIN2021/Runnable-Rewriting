# Archived Legacy QEMU

This is the old patched QEMU 2.4.50 tree that previously lived at
`Runnable-Rewriting/qemu/`.

It is kept only as historical reference and as the legacy PTC ABI source for
transition shims. It should not be used as the default QEMU source for new
experiments. QEMU V2 experiments should use an explicit modern source tree, for
example QEMU 10.2.3 via `--qemu-src` or `RUNNABLE_QEMU_V2_UPSTREAM_SRC`.
